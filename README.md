# Thibodaux T-Box

Homepage for Thibodaux T-Box, an indoor golf simulator in Thibodaux, Louisiana.

`index.html` is a single self-contained page (GSAP 3.12.5 and Lenis 1.1.14 load from CDNs). The logo, favicon and nav lockups are embedded in the page. `assets/` holds the cropped logo files for reuse.

## Settings

At the top of the script in `index.html`:

- `BOOKING_URL`: booking platform link used by every Book Now, Book a Tee Time and gift card button
- `MEMBER_LOGIN_URL`: member login on the booking platform
- `FOUNDING_DEADLINE`: target opening day for the founding member countdown
- `SOCIAL`: Instagram and Facebook links (shown once filled in)

The brand green is `--brand` at the top of the stylesheet.
